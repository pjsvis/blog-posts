## 1. Executive Summary (TL;DR)

1. **The Phenomenon:** A growing trend in software management—termed "Orchestrator Drift"—advocates for senior engineers shipping large, model-generated codebases ($10^4$–$10^5$ lines of code) to production without line-level human audit, relying instead on high-level design specs (`DESIGN.md`) and generated documentation.
2. **The Operational Flaw:** Generating 100,000 lines of un-read code in 40 minutes does not compress 3 months of engineering work into minutes; it front-loads 3 months of un-audited technical debt, concurrency edge cases, and hidden state drift into a single deployment window.
3. **The Directive:** System operators are explicitly reminded that **un-audited code is un-bounded risk**. Operating as a "conductor" over non-deterministic code generators does not relieve the operator of legal, operational, or technical liability.

## 2. Operational Context: The "Pilot Manual" Fallacy

Recent industry publications argue that senior developers ("Orchestrators") no longer need to read the code shipped under their authority, asserting that a model-generated "pilot manual" or system architecture document provides sufficient operational baseline for emergency intervention.

The Office of AI Human-System Reliability rejects this premise.

In high-reliability systems, you cannot "land the plane without autopilot" using a flight manual written mid-flight by the autopilot itself. When a concurrency deadlock, memory corruption, or zero-day vulnerability hits production at 2:00 AM, high-level design documents provide zero diagnostic leverage over raw execution state.

## 4. Required Systems Directives

All personnel deploying AI-generated code to production environments must immediately enforce the following operational boundaries:

1. **Mandatory Bounded Auditing:** No code module generated by an automated system shall be merged to production without a human-verified test suite and deterministic line-level review corresponding to the module's blast radius.
2. **No Self-Referential Documentation:** Systems documentation, support runbooks, and "pilot manuals" used for emergency triage **must not** be generated solely by the same model instance that produced the target codebase. Independent verification or human authorship is required.
3. **Strict Blast-Radius Containment:** Highly automated, multi-agent code generators must be constrained to ephemeral microservices with strict memory, network egress, and execution limits. Un-audited code must never be deployed directly to core infrastructure or critical data paths.
